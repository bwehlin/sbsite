StableBear
Install Features Docs

A computational package for discrete objects in Python and C++.

StableBear is an open-source Python package with a C++/CUDA backend for GPU-accelerated computation on piecewise constant functions: stable ranks, Euler characteristic curves, Betti curves and the distances and kernels between them.

Read the docs Install

Install

pip install stablebear

Then import stablebear as sb and follow the documentation for examples.

What it computes

Stable ranks

A stable rank turns a persistence module into a non-increasing piecewise constant function. StableBear computes stable ranks with a GPU-accelerated backend.

Euler characteristic curves

The Euler characteristic of each sublevel set of a filtration, as a step function of the filtration value.

Betti curves

The Betti numbers of each sublevel set (H₀, H₁, ...), as step functions of the filtration value.

Distances and kernels

Pairwise Lp distances between stable rank curves, and kernels between them.
